# Progress Notes – Progress Notes & Invoicing App for Health Professionals

Progress Notes is a native Android application designed for allied health and support professionals to easily record client session notes, track time (billable and non-billable) and generate invoice-ready data.
Originally developed as a personal project for my wife (a practicing health professional), this app is now being published publicly to showcase my engineering, architecture, and product-thinking skills.
The UI/UX is still basic and could use improvment but performs the basic requirements needed for the base concept.

### 🔐 Secure Authentication

* Sign up/in flow with Phone number and SMS code authentication using Firebase Auth.

### 📝 Progress Notes Management

* Create and edit progress notes for each client

### ⏱️ Time & Billing Tracking

* Track labour type and duration for invoicing requirements

* Associate multiple notes with a single invoice

* Split client charges into seperate invoices when exporting

* Export-ready invoice data generated by combining times & note data

### 🛠️ Tech Stack

* Language: 100% Kotlin

* Architecture: MVVM + Clean Architecture principles

* UI: Jetpack Compose

* Data Persistance: Firebase Storage

* Dependency Injection: Hilt

* Asynchronous: Kotlin Coroutines + Flows

* Build Tools: Gradle (KTS)
